A professional **Admin Dashboard Application** built with **React.js**, styled with **Material UI**, featuring interactive charts using **Nivo**, and deployed on **Firebase Hosting**.

## ✨ Features
- Responsive **Admin Dashboard UI**  
- **Light/Dark Mode** with Material UI Theme  
- **Interactive Charts** (Line, Bar, Pie) with Nivo  
- **Form Validation** using React-Hook-Form  
- Fast & Secure **Deployment** on Firebase  

---

## 🛠 Tech Stack
- **Frontend:** React.js, Material UI, Nivo, React-Hook-Form  
- **Deployment:** Firebase Hosting
